<objective>
Fix Student-t double-division bug and centralize prior construction into one shared helper.

Purpose: The Student-t prior scale is ~100x too small because the hook divides the interval by 100 before passing to computeStudentTPriorScale, which also divides by 100 internally. Additionally, prior construction is duplicated across 3 locations (hook, form preview, results section) with the Student-t case using Normal-calibrated parameters instead of t-calibrated scale. A single buildPriorFromInputs() helper eliminates both problems.

Output: `buildPriorFromInputs()` in prior.ts, all 3 call sites migrated, tests proving Student-t scale correctness.
</objective>
