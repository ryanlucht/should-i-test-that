    - Decode of unknown version (v > SCHEMA_VERSION): Returns null (not throw) so caller can handle gracefully
    - Decode of malformed string (invalid base64, invalid JSON, non-object): Returns null (not throw)
    - Decode validation (addresses review concern: runtime validation of decoded payload):
      - Numeric fields must be typeof 'number' and finite (reject NaN, Infinity) or null
      - String enum fields (priorType, priorShape, thresholdScenario, thresholdUnit) must be one of their allowed values or null
      - studentTDf must be 3, 5, 10, or null
      - baselineConversionRate must be in [0, 1] if present (it's a decimal rate)
      - trafficSplit must be in (0, 1] if present
      - eligibilityFraction must be in (0, 1] if present
      - If any field fails validation, decodeWizardState returns null (entire payload rejected -- partial acceptance is too risky)
    - Decode fills missing keys with initialInputs defaults (forward compat: new fields added later get defaults)
    - Short keys: Each WizardInputs key maps to a 1-2 character short key. Include an inline comment table mapping shortKey -> field name for maintainability.
    - Encoding uses hash fragment format: the encoded string is meant to be placed after "#s=" in the URL
  </behavior>
  <implementation>
    Create src/lib/url-codec.ts with:

    1. SHORT_KEY_MAP: Record mapping full WizardInputs keys to short 1-2 char keys. Include an inline comment table documenting the mapping for future maintainability:
       ```
       // Short key mapping (keep this comment in sync with the map below):
       // bc = baselineConversionRate    av = annualVisitors
       // ul = visitorUnitLabel          vc = valuePerConversion
       // pt = priorType                 pl = priorIntervalLow
       // ph = priorIntervalHigh         ps = priorShape
       // df = studentTDf                ts = thresholdScenario
       // tu = thresholdUnit             tv = thresholdValue
       // td = testDurationDays          dt = dailyTraffic
       // sp = trafficSplit              ef = eligibilityFraction
       // dl = decisionLatencyDays
       ```

    2. REVERSE_KEY_MAP: Computed inverse of SHORT_KEY_MAP

    3. SCHEMA_VERSION = 1

    4. encodeWizardState(inputs: WizardInputs): string
       - Build compact object: for each key in WizardInputs, if value !== null AND value !== initialInputs[key], add SHORT_KEY_MAP[key]: value
       - Add "v": SCHEMA_VERSION
       - JSON.stringify the compact object
       - Base64url encode (btoa with URL-safe chars: + -> -, / -> _, remove trailing =)
       - Return the encoded string (caller adds "#s=" prefix)

    5. validateDecodedPayload(decoded: Record<string, unknown>): WizardInputs | null
       - Internal helper. Takes the raw decoded object (with full keys, post-migration).
       - For each numeric field: check typeof === 'number' && Number.isFinite(value), or value is null
       - For enum fields: check value is one of the allowed literals or null
       - For domain constraints: baselineConversionRate in [0,1], trafficSplit in (0,1], eligibilityFraction in (0,1], studentTDf in {3,5,10,null}
       - If any check fails, return null
       - Otherwise, return the validated WizardInputs object

    6. decodeWizardState(encoded: string): WizardInputs | null
       - Try: base64url decode (reverse the URL-safe char substitution, atob)
       - Try: JSON.parse; if result is not a plain object, return null
       - Read "v" field; if missing or > SCHEMA_VERSION, return null
       - If v < SCHEMA_VERSION, run migration chain (scaffold: MIGRATIONS record keyed by version number, each transforms payload to next version)
       - Map short keys back to full keys using REVERSE_KEY_MAP
       - Merge with initialInputs (spread initialInputs first, then decoded values on top) so missing keys get defaults
       - Run validateDecodedPayload on the merged result
       - Return validated WizardInputs or null

    7. Type the function signatures with JSDoc comments explaining the encoding format.
