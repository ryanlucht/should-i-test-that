    Implementation in src/App.tsx:

    1. Add imports: `import { useEffect, useRef } from 'react'` (replace existing `useState` only import), `import { decodeWizardState } from '@/lib/url-codec'`.

    2. Add a `useRef<boolean>(false)` named `hydrated` to prevent double-hydration on StrictMode re-renders.

    3. Add a `useEffect` that runs once on mount (empty deps) BEFORE the render:
       ```typescript
       useEffect(() => {
         if (hydrated.current) return;
         const hash = window.location.hash;
         if (!hash.startsWith('#s=')) return;

         const encoded = hash.slice(3); // Remove "#s="
         const decoded = decodeWizardState(encoded);
         if (!decoded) return;

         hydrated.current = true;

         // Hydrate store with decoded inputs
         const store = useWizardStore.getState();
         for (const [key, value] of Object.entries(decoded)) {
           store.setInput(key as keyof WizardInputs, value as WizardInputs[keyof WizardInputs]);
         }

         // Enable guide for recipients (D-07)
         store.setGuideEnabled(true);

         // Mark all non-results sections as completed so recipient can navigate freely
         // Sections: 0=Baseline, 1=Uncertainty, 2=Threshold, 3=TestDesign (4=Results is not "completed")
         for (let i = 0; i < 4; i++) {
           store.markSectionComplete(i);
         }

         // Skip welcome page -- go directly to calculator
         setCurrentPage('calculator');

         // Clean the URL hash so it doesn't interfere with future sharing
         window.history.replaceState(null, '', window.location.pathname);
       }, []);
       ```

    4. Also pull `setInput` and `markSectionComplete` from the store at the component level OR use `useWizardStore.getState()` directly inside the effect (preferred since it avoids re-render subscription). Use the store's imperative API.

    5. Import `WizardInputs` type: `import type { WizardInputs } from '@/types/wizard'`.

    Note: The hydration effect uses `useWizardStore.getState()` (Zustand imperative access) instead of the hook form, which avoids subscribing to store changes and is correct for a one-shot initialization effect.
