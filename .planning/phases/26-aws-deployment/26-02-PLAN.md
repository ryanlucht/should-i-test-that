<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Configure Custom Domain</name>
  <action>
The user must add shouldwetestthat.com to the Vercel project and configure DNS. Provide these instructions:

**Step 1: Add Domain in Vercel**

1. Go to Vercel project → Settings → Domains
2. Type `shouldwetestthat.com` and click "Add"
3. Vercel will show DNS configuration instructions — typically:
   - **A Record:** `76.76.21.21` (Vercel's IP)
   - **CNAME for www:** `cname.vercel-dns.com`

**Step 2: Configure GoDaddy DNS**

1. Go to https://dcc.godaddy.com/manage-dns (or My Products → shouldwetestthat.com → DNS)
2. Keep GoDaddy as nameserver (no need to change nameservers like AWS required)
3. Add/edit these DNS records:
   - **A Record:** Host=`@`, Points to=`76.76.21.21`, TTL=600
   - **CNAME Record:** Host=`www`, Points to=`cname.vercel-dns.com`, TTL=600
4. Delete any conflicting A or CNAME records for `@` or `www`

**Step 3: Wait for DNS + TLS**

- DNS propagation: usually 5-30 minutes (check at https://dnschecker.org/#A/shouldwetestthat.com)
- Vercel auto-provisions a Let's Encrypt TLS certificate once DNS resolves
- Certificate issuance: usually 1-5 minutes after DNS propagation

**Step 4: Verify Domain**

Check that all three work:
- https://shouldwetestthat.com
- https://www.shouldwetestthat.com
- http://shouldwetestthat.com (should redirect to HTTPS)

**Troubleshooting:**
- If Vercel shows "Invalid Configuration": DNS hasn't propagated yet. Wait and retry.
- If certificate is pending: DNS must resolve first. Check dnschecker.org.
- If www works but apex doesn't (or vice versa): verify both A and CNAME records are set.
  </action>
