<objective>
Fix Student-t prior calibration and all Student-t display logic so the distribution honors the user's 90% credible interval.

Purpose: The current code uses the Normal quantile (Z_95 = 1.6449) to derive the Student-t scale parameter, which silently widens the 90% interval. A user who enters [-8.22%, +8.22%] with df=3 actually gets a 90% interval of ~[-11.76%, +11.76%]. This fix uses the t-quantile so the user's interval is preserved. Chart shading, plotting range, and posterior grid bounds are also corrected to use t-quantiles.

Output: Corrected Student-t calibration in prior.ts, corrected chart shading/range, corrected posterior grid bounds, and tests proving the round-trip property.
</objective>

           df: number
         ): PriorParameters {

           const L_high = intervalHighPercent / 100;
