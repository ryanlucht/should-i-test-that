<objective>
Fix Student-t prior calibration and all Student-t display logic so the distribution honors the user's 90% credible interval.

Purpose: The current code uses the Normal quantile (Z_95 = 1.6449) to derive the Student-t scale parameter, which silently widens the 90% interval. A user who enters [-8.22%, +8.22%] with df=3 actually gets a 90% interval of ~[-11.76%, +11.76%]. This fix uses the t-quantile so the user's interval is preserved. Chart shading, plotting range, and posterior grid bounds are also corrected to use t-quantiles.

Output: Shared Student-t quantile helper, corrected Student-t calibration in prior.ts, corrected chart shading/range, corrected posterior grid bounds, and tests proving the round-trip property.
</objective>

       /**
        * Shared Student-t quantile helpers.
        * Centralizes all Student-t quantile computation to avoid drift
        * from hardcoded constants scattered across files.
        */
       import jStat from 'jstat';

       /**
        * Compute symmetric quantile bounds for a location-scale Student-t.
        * @param mu - location parameter
        * @param scale - scale parameter (sigma_L for Student-t)
        * @param df - degrees of freedom (must be > 0)
        * @param lowerP - lower quantile probability (e.g. 0.005 for 0.5th percentile)
        * @param upperP - upper quantile probability (e.g. 0.995 for 99.5th percentile)
        * @returns { low, high } bounds
        */
       export function studentTQuantileBounds(
         mu: number, scale: number, df: number,
         lowerP: number, upperP: number
       ): { low: number; high: number } {
         if (df <= 0 || !isFinite(df)) {
           // Safe fallback: use Normal-like 4-sigma bounds (addresses Codex df guardrail concern)
           return { low: mu - 4 * scale, high: mu + 4 * scale };
         }
         return {
           low: mu + scale * jStat.studentt.inv(lowerP, df),
           high: mu + scale * jStat.studentt.inv(upperP, df),
         };
       }

       /**
        * Compute 90% credible interval for a location-scale Student-t.
        * Convenience wrapper for the most common quantile pair.
        */
       export function studentTInterval(
         mu: number, scale: number, df: number
       ): { low: number; high: number } {
         return studentTQuantileBounds(mu, scale, df, 0.05, 0.95);
       }
       ```

         /**
          * Derive Student-t scale parameter from user's 90% credible interval.
          * Uses t-quantile instead of Normal quantile (per ENG-01, D-10).
          *
          * Mathematical basis:
          * For Student-t(location=mu, scale=s, df), the 90% interval spans
          * [mu + s * t_inv(0.05, df), mu + s * t_inv(0.95, df)]
          * So: s = halfWidth / t_inv(0.95, df)
          *
          * @param df - must be > 0; if invalid, falls back to Normal quantile
          */
         export function computeStudentTPriorScale(
           intervalLowPercent: number,
           intervalHighPercent: number,
           df: number
         ): PriorParameters {
           const L_low = intervalLowPercent / 100;
           const L_high = intervalHighPercent / 100;
           const mu_L = (L_low + L_high) / 2;
           // Guard against invalid df (addresses Codex df guardrail concern)
           if (df <= 0 || !isFinite(df)) {
             // Fall back to Normal calibration as safe default
             return computePriorFromInterval(intervalLowPercent, intervalHighPercent);
           }
           const t_95 = jStat.studentt.inv(0.95, df);
           const sigma_L = (L_high - L_low) / (2 * t_95);
           return { mu_L, sigma_L };
         }
         ```
