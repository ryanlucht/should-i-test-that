## What Was Built

### WaterfallBlock (WaterfallBlock.tsx)

New component rendering a six-step causal narrative:

1. Default decision (ship / not ship)
2. Prior uncertainty range (priorLow to priorHigh, formatted as percentages)
3. Test informativeness (pDecisionChange as probability percent)
4. Gross value of better decisions (testValue = evsiDollars, smart currency)
5. Timing cost of waiting (timingCost = evsiDollars - netValueDollars, always positive)
6. Net value with color coding (text-primary positive, text-destructive negative)

Structure: `<section aria-label="Why this result?">` wrapping `<h4>` + `<ol>` with 6 `<li>` items. Each step has a `<span className="font-semibold text-muted-foreground">N.</span>` prefix inline with body text. Uses `formatSmartCurrency`, `formatProbabilityPercent`, `formatPercentage` from `@/lib/formatting` and `cn` from `@/lib/utils`.

12 TDD tests covering: heading/section structure, 6 numbered steps, defaultDecision display, prior range values, pDecisionChange percent, testValue currency, timingCost currency, netValue color coding (positive and negative), card styling classes.

### SupportingCard Extension (SupportingCard.tsx)

Added optional `children?: ReactNode` prop. When provided, renders `<div className="mb-1">{children}</div>` instead of the single value div. `value` made optional to support children-only usage. Backward compatible — all existing callsites with a `value` string continue to work unchanged.
