## What Was Built

### Types (types.ts)
Added two optional fields to both `EVSIResults` and `NetValueResults`:
- `pStopsShip?: number` — probability the test stops you from shipping (default=ship, posterior=don't-ship)
- `pConvincesShip?: number` — probability the test convinces you to ship (default=don't-ship, posterior=ship)

Both are marked optional (`?`) for backward compatibility with all existing consumers.

### Engine: calculateEVSIMonteCarlo (evsi.ts)
Added `stopsShipCount` and `convincesShipCount` directional counters to the MC loop. Inside the `if (posteriorDecision !== defaultDecision)` block, increments the correct counter based on `defaultDecision`. After the loop, computes `pStopsShip = stopsShipCount / validSamples` and `pConvincesShip = convincesShipCount / validSamples`. All early-return guard paths (zero arm size, invalid CR0, zero valid samples) return `pStopsShip: 0, pConvincesShip: 0`.

### Engine: calculateEVSINormalFastPath (evsi.ts)
Derives directional split from `defaultDecision`:
- If `defaultDecision === 'ship'`: `pStopsShip = probabilityTestChangesDecision, pConvincesShip = 0`
- If `defaultDecision === 'dont-ship'`: `pConvincesShip = probabilityTestChangesDecision, pStopsShip = 0`

All early-return guards also include `pStopsShip: 0, pConvincesShip: 0`.

### Engine: calculateNetValueMonteCarlo (net-value.ts)
Same pattern as EVSI MC — directional counters, increment inside decision-change block, compute probabilities after loop, add to all return paths.

### Tests Added (7 new tests)
- EVSI MC: default=ship → pConvincesShip=0, pStopsShip>0
- EVSI MC: default=dont-ship → pStopsShip=0, pConvincesShip>0
- EVSI MC: identity (pStopsShip + pConvincesShip === probabilityTestChangesDecision)
- EVSI MC: zero samples → pStopsShip=0, pConvincesShip=0
- EVSI fast-path: default=ship → pStopsShip=probabilityTestChangesDecision, pConvincesShip=0
- EVSI fast-path: default=dont-ship → pConvincesShip=probabilityTestChangesDecision, pStopsShip=0
- NetValue MC: identity (pStopsShip + pConvincesShip === probabilityTestChangesDecision)
- NetValue MC: default=ship → pConvincesShip=0
- NetValue MC: default=dont-ship → pStopsShip=0
- NetValue MC: zero samples → pStopsShip=0, pConvincesShip=0
