## What Was Built

### FAQAccordion (FAQAccordion.tsx)

New component rendering four collapsed-by-default accordion explainer items:

1. **"What's driving the value you've calculated?"** — dynamic content with traffic, valuePerConversion, priorLow/High range, pDecisionChange, and timingCost
2. **"How is the value of better decisions calculated?"** — four-step numbered process explanation with testValue (evsiDollars) as currency
3. **"What would make this test worth more? Worth less?"** — generic worth-more/worth-less bullet lists (no personalized sensitivity ranking per D-04)
4. **"Why does waiting reduce the value?"** — explanation of opportunity cost during test + readout with timingCost as currency

Structure: outer `<div className="bg-card border border-border rounded-xl p-6 space-y-1">` wrapping four `AccordionItem` sub-components. Each item uses `role="button"`, `aria-expanded`, `tabIndex={0}`, and `onKeyDown` (Enter/Space) per the ValueBreakdownCard accordion pattern. `ChevronDown` when collapsed, `ChevronUp` when expanded. Expanded panel uses `text-sm text-muted-foreground bg-muted/30 rounded-lg p-3 space-y-2`.

State: four independent `useState(false)` booleans — items open/close independently with no mutual exclusion.

Formatters used: `formatSmartCurrency`, `formatProbabilityPercent`, `formatPercentage`, `formatNumber` from `@/lib/formatting`.

11 TDD tests covering: all four trigger labels, collapsed-by-default (aria-expanded=false), expand/collapse on click, independence, Enter key toggle, Space key toggle, dynamic value content in accordions 1/2/4, card wrapper classes.

### ResultsSection Layout Update (AdvancedResultsSection.tsx)

**EVSI Intuition block removed** — the `<div className="rounded-xl border bg-muted/30 border-muted p-4 space-y-2">` block with "How to interpret $X" copy is fully deleted.

**FAQAccordion wired in its place** at layout position 7 (per UI-SPEC):

```tsx
<FAQAccordion
  traffic={inputs.dailyTraffic ?? 0}
  valuePerConversion={inputs.valuePerConversion ?? 0}
  priorLow={priorLow}
  priorHigh={priorHigh}
  pDecisionChange={results.evsi.probabilityTestChangesDecision}
  testValue={results.evsi.evsiDollars}
  timingCost={results.evsi.evsiDollars - results.netValueDollars}
  netValue={results.netValueDollars}
/>
```
