    **Step A: Rewrite `computeEffectivePriorMetrics` in evsi.ts to be deterministic.**

    Replace the Monte Carlo sampling loop (lines 50-92) with analytic/numerical computation:

    1. **Normal prior**: Use `truncatedNormalMeanTwoSided(mu_L, sigma_L, L_min, L_max)` for effectivePriorMean. For effectiveProbClears: compute `(1 - cdf_truncated(threshold_L))` where `cdf_truncated(x) = (Phi((x - mu)/sigma) - Phi((L_min - mu)/sigma)) / (Phi((L_max - mu)/sigma) - Phi((L_min - mu)/sigma))`. The existing `standardNormalCDF` function provides Phi.

    2. **Uniform prior**: Clip bounds to feasibility: `a = max(low_L, L_min)`, `b = min(high_L, L_max)`. If `b <= a`, this is the infeasible case (handle in Task 2). Mean = `(a + b) / 2`. ProbClears = `max(0, min(b, Infinity) - max(a, threshold_L)) / (b - a)` (fraction of uniform mass above threshold after truncation).

    3. **Student-t prior** (addresses review concern: Student-t numerical integration underspecified):
       Use **composite Simpson's rule** with a **200-point grid** (matching the existing 200-point posterior grid convention from evsi.ts line 197) on the interval [L_min, L_max]. Specifically:

       - Grid: 200 evenly-spaced points from L_min to L_max (201 points for Simpson's 1/3 rule with even number of intervals; use 200 intervals = 201 nodes).
       - Step size: `h = (L_max - L_min) / 200`
       - For effectivePriorMean: integrate `L * pdf(L, prior)` over [L_min, L_max] using Simpson's 1/3 rule, then divide by Z where Z = integral of `pdf(L, prior)` over [L_min, L_max] (also computed via Simpson's rule in the same pass). The pdf for location-scale Student-t is available via jStat: `jStat.studentt.pdf((L - mu_L) / sigma_L, df) / sigma_L`.
       - For effectiveProbClears: integrate `pdf(L, prior)` over [max(threshold_L, L_min), L_max] using the same grid (or a subgrid), then divide by Z.
       - **Near-zero mass handling**: If Z < 1e-10, this is the infeasible case (defer to Task 2's NaN return).
       - **Convergence note**: 200-point Simpson's rule achieves O(h^4) convergence. For the smooth Student-t pdf on typical feasibility intervals, this gives >6 digits of precision, far exceeding the MC noise it replaces.
       - **Normalization**: The Z divisor ensures we compute the truncated distribution mean, not just a weighted integral. This is mathematically equivalent to E[L | L_min <= L <= L_max].
       - **Tail handling**: L_min and L_max are already set by `liftFeasibilityBounds(CR0)` which constrains to [-1, (1/CR0)-1]. No additional tail truncation needed beyond these bounds.

    Remove the `numSamples` parameter since MC is no longer used. Updated signature:

    ```typescript
    /**
     * Checks if effective-prior metrics indicate an infeasible prior
     * (zero feasible mass within conversion-rate bounds).
     * Returns a typed CalculationWarning if infeasible, null otherwise.
     *
     * This is the ONLY place NaN from infeasible priors is converted to
     * a user-facing warning. MC functions that call this return evsiDollars=0
     * and netValueDollars=0 with this warning -- NaN never reaches dollar outputs.
     */
    export function checkInfeasiblePriorWarning(
      effectivePriorMean: number,
      effectiveProbClears: number
    ): CalculationWarning | null {
      if (isNaN(effectivePriorMean) || isNaN(effectiveProbClears)) {
        return {
          code: 'infeasible_prior_support',
          message: 'The prior distribution has no feasible mass within conversion rate bounds. Check that your prior interval is compatible with the baseline conversion rate.',
        };
      }
      return null;
    }
    ```
