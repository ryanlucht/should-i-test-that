## Key Changes

### Task 1: Deterministic Effective Prior Metrics

- **Normal prior**: Uses `truncatedNormalMeanTwoSided(mu, sigma, L_min, L_max)` for effectivePriorMean. For effectiveProbClears: analytic formula using CDF ratio `(PhiMax - PhiThresh) / Z`.
- **Uniform prior**: Closed-form clipped bounds `a = max(low_L, L_min)`, `b = min(high_L, L_max)`. Mean = `(a + b) / 2`. ProbClears = fraction of mass above threshold.
- **Student-t prior**: 200-point composite Simpson's 1/3 rule (201 nodes) on [L_min, L_max]. O(h^4) convergence. Computes Z (normalization), sumLpdf (for mean), and aboveT (for probClears) in a single pass.
- **Compute-once pattern**: `effectivePriorMetrics` computed once by caller, passed as parameter to both `calculateEVSIMonteCarlo` and `calculateNetValueMonteCarlo`. Default parameter fallback maintains backward compatibility.
- **Hook integration**: `EVSICalculationResults` now includes `effectivePriorMean: number` field. Falls back to raw prior mean when effective mean is NaN (infeasible prior).
- **Stale comment fixed**: net-value.ts comment corrected from "Clamped to max(0)" to "Net value CAN be negative".

### Task 2: Infeasible Prior Warning and Real-Valued Sample Sizes

- **infeasible_prior_support**: Added to `CalculationWarning` code union in types.ts.
- **checkInfeasiblePriorWarning**: New helper in feasibility.ts. Single NaN firewall: detects NaN from `computeEffectivePriorMetrics` and returns typed warning. Docstring explicitly states "NaN never reaches dollar outputs."
- **MC function guards**: Both `calculateEVSIMonteCarlo` and `calculateNetValueMonteCarlo` call `checkInfeasiblePriorWarning` after receiving effective metrics. On infeasible prior, they return `evsiDollars: 0` / `netValueDollars: 0` with the warning -- NaN never propagates to charts, formatters, or exports.
- **Default decision**: Both MC functions now use effective (truncated) prior mean for default decision instead of raw prior mean. This correctly reflects truncation effects on the decision boundary.
- **Real-valued sample sizes**: Removed `Math.floor` from `deriveSampleSizes`. Results are real-valued in the calculation layer; rounding to integers is deferred to the display layer.

## Decisions Made

1. **Default parameter pattern**: `effectivePriorMetrics` uses a default parameter (`= computeEffectivePriorMetrics(...)`) rather than being strictly required with no default. This maintains backward compatibility for tests and direct callers that don't pass it explicitly, while the hook and worker always pass it explicitly for the compute-once guarantee.

2. **Default decision uses truncated mean**: Both MC functions now derive `defaultDecision` from the effective (truncated) prior mean rather than the raw (untruncated) prior mean. When truncation is material (e.g., CR0=0.90 with Normal(0, 0.10)), the truncated mean can differ in sign from the raw mean, changing the default decision.

3. **Student-t symmetry tolerance**: The 200-point Simpson's grid has a slight asymmetry artifact at the threshold boundary point (endpoint vs midpoint weight). Symmetry test uses 1 decimal place tolerance (0.05 tolerance) rather than 2 decimal places.
